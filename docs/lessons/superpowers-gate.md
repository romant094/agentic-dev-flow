## Open findings carried over

- **D2 — the preflight paragraph is repeated in four command files with no canonical home**
  (`adf-deferred-findings.md`, section on deferred restatements; D3, the "do not restore the
  files yourself" reaction, is the same shape). The port fixes it: the gate's text lives once
  in the script's output and the core's commands carry a one-line step that runs it.
- **The gate does not read `.claude/settings.local.json`** (design, round-six deferred
  findings). Fixed by the merge order above.
- **Two script tests depend on the process working directory** (design, round-four deferred
  findings). Fixed for this script by the fixture-driven test above.
- **The gate depends on private Claude Code state** (design Risks). Still open; the port keeps
  the loud-failure mitigation.
- **`archive.md`'s integrity markers do not include `check-superpowers.mjs`.** Found in this
  pass, not recorded in the origin. Moot in the port, since the marker check is not ported.
- **A project-scope install for another project passes the gate.** Found in this pass, not
  recorded in the origin. Fixed by the scope rule.
