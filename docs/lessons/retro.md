## Open findings carried over

- **H5 — `--since-retro` reads a stale `origin/develop`** (`DF:390`). Fixed: the ref is fetched
  before it is read, and archive's report and the retrospective name the fetch time.
- **The window retrospective was never run in the origin.** Its behaviour is compared with the
  port's only through `scripts/parity/origin-window.mjs`, over the origin's records.
- **Re-derivation is not measured.** The signal needs the files each dispatch read, which no
  record keeps; the agent can name it only from a flow file it opens.
- **The lessons references in `schema/retro-waiting.json` are not checked by a test.** Each names
  a row by the start of its rule cell; a renamed row would leave the agent a dead reference.
